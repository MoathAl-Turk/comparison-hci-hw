# AI-Generated Web Interfaces Comparison
**Human-Computer Interaction (HCI) - Assignment 1**

This repository contains the files and evaluation report for our HCI assignment, which explores how different AI tools generate web interfaces based on the exact same prompt.

**[View the Live Project Hub Here](https://moathal-turk.github.io/comparison-hci-hw/)**

---

## Project Overview
* **Group Members:** Ali Sharawi & Moath Al-Turk
* **Selected Idea:** Local Specialty Coffee Shop
* **Visual Style:** Minimalist

### The Prompt
> "Create a modern, visually appealing webpage for a local coffee shop. Include a clear heading, a brief introduction about our locally roasted beans, a menu section featuring sample espresso drinks and pastries with prices, and a contact section with our opening hours. Use a Minimalist style, with a clean layout, ample whitespace, a simple black-and-white color palette with warm brown accents, clear navigation, and highly readable text. Generate a webpage that I can preview."

---

## Tools Evaluated & Results
We used the prompt above to generate three different webpages. Here is a summary of our evaluation (scored out of 25):

### 1. Claude ("Ember & Oak") - Score: 24.5/25 🏆 (Winner)
* **Overview:** Pure minimalist aesthetic with a crisp white canvas, black text, and warm brown accents.
* **Why it won:** It provided the calmest, fastest, and most readable user experience. It perfectly honored the "minimalist" prompt with generous whitespace, clean typography, and thin horizontal dividers.
* **Navigation:** Compact 3-item navbar and short scroll height require the least effort.

### 2. Google AI Studio ("KROMA") - Score: 22.5/25
* **Overview:** Editorial magazine layout; off-white canvas, charcoal text, bronze accents.
* **Strengths:** High commercial polish with working JavaScript tab switching.
* **Weaknesses:** Feature bloat. It added unrequested sections and dead e-commerce buttons (ORDER AHEAD), making it visually dense.

### 3. ChatGPT ("ground&grain.") - Score: 20.0/25
* **Overview:** Cozy café theme; warm beige canvas, heavy dark-brown contrast blocks.
* **Strengths:** Automatically localized the coffee shop to Amman, Jordan with Jordanian Dinar (JD) pricing.
* **Weaknesses:** Left raw placeholder strings (e.g., "Replace with your street address") and used heavy dark containers that reduced the requested whitespace.
