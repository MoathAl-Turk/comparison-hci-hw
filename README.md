AI-Generated Web Interfaces Comparison

Human-Computer Interaction (HCI) - Assignment 1

This repository contains the files and evaluation report for our HCI assignment, which explores how different AI tools generate web interfaces based on the exact same prompt.

Live Project Hub: View the Websites Here

Project Overview

Selected Idea: Local Specialty Coffee Shop

Visual Style: Minimalist

The Prompt: "Create a modern, visually appealing webpage for a local coffee shop. Include a clear heading, a brief introduction about our locally roasted beans, a menu section featuring sample espresso drinks and pastries with prices, and a contact section with our opening hours. Use a Minimalist style, with a clean layout, ample whitespace, a simple black-and-white color palette with warm brown accents, clear navigation, and highly readable text. Generate a webpage that I can preview."

Tools Evaluated & Results

We used the prompt above to generate three different webpages. Here is a summary of our evaluation (scored out of 25):

Claude ("Ember & Oak") - Score: 24.5/25 (Winner)

Overview: Pure minimalist aesthetic with a crisp white canvas, black text, and warm brown accents.

Why it won: It provided the calmest, fastest, and most readable user experience. It perfectly honored the "minimalist" prompt with generous whitespace and a flat, linear hierarchy that made finding prices and hours effortless.

Google AI Studio ("KROMA") - Score: 22.5/25

Overview: An editorial magazine layout with charcoal text and bronze accents.

Pros/Cons: Highly stylish with working JavaScript tabs, but over-engineered. It suffered from feature bloat, adding unrequested sections and dead e-commerce buttons ("Order Ahead") that cluttered the user experience.

ChatGPT ("ground&grain.") - Score: 20.0/25

Overview: A cozy café theme with heavy dark-brown contrast blocks.

Pros/Cons: It impressively localized the shop to Amman, Jordan (using JD currency and Sun-Thu workweek hours). However, it left raw placeholder text (e.g., "Replace with your street address") and its heavy design reduced the requested whitespace.
